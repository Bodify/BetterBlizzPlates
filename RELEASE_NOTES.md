# BetterBlizzPlates 2.2.1
## All versions
### New
- Execute Indicator: New setting so that the execute skull can now be attached to the threshold spot as well.
- "Color Castbar Border" setting under "Change Nameplate Border Color". Colors the castbar border the same as the nameplate border. On by default but can we be turned off.
### Tweak
- Quest Indicator: Fixup Quest Indicator's color priority over other things. (and fix tapped mobs getting quest color)
## Forever
### Tweak
- "Show resource on target nameplate" and "Anchor resource underneath healthbar/castbar" are now on by default for new users.
- Update JFarm profile (www.twitch.tv/jfarm_)
### Bugfix
- Fix "Druid: Always Show Combo Points" causing a lua error due to the recent WoW Forever Beta update.
## Retail & Forever
### New
- Nameplate Auras: Test mode now also previews the Personal Bar buffs.
- Misc: "Low Health Texture Fix" setting. Fixes the healthbar texture "glitching" at low health due to Blizzard reasons. Changes the texture a bit too, off by default.
### Tweak
- On 12.1.5 these can't work on arena enemies: "Short" and "Heal" spec names, healer healthbar color, and Class Indicator "Only Show Healer" and "Always Show Healers/Tanks".
- Healer Indicator: New cross icon.
### Bugfix
- Fix Blizzard's nameplate health numbers sometimes being way too large.
- Classic Castbar: Fix "Hide Shield" removing the castbar border on uninterruptible casts. It now shows the normal border in gray.
- Class Indicator & Blitz Indicator: Fix flag carrier icons not always updating in battlegrounds. (2nd attempt)
- Fix nameplate names sometimes being hidden behind the healthbar with some settings.
